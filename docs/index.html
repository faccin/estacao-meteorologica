Arquitetura

A estação usa dois módulos Heltec conversando por rádio LoRa (915 MHz — faixa liberada no Brasil), não por WiFi. Isso permite colocar os sensores a centenas de metros da Orange Pi, mesmo sem sinal de wifi ali. O WiFi da Orange Pi fica reservado só para os celulares dos alunos acessarem o painel.

Por que dois Heltec? O nó remoto pode ficar longe da Orange Pi — no telhado, num poste, num terreno aberto — sem precisar de sinal WiFi ali. Só a base, que fica conectada por cabo USB na Orange Pi, precisa estar por perto.

Ligações elétricas

Os sensores conectam só na Heltec #1 (nó remoto). A Heltec #2 (base) não tem sensor nenhum — ela só recebe o rádio e passa pra Orange Pi via USB.

A Heltec #2 (base) não precisa de nenhuma ligação de sensor — só o cabo USB para a Orange Pi, que também a alimenta.

Configuração no Arduino IDE

Selecione a placa "WiFi LoRa 32 (V3)" mesmo tendo a V4 — o pacote de placas da Heltec ainda não separa uma entrada específica para a V4, mas o mapeamento de pinos é compatível.

Frequência: os dois sketches usam 915.0 MHz — a faixa correta para uso no Brasil (ANATEL). Não altere sem necessidade, e mantenha o mesmo spreading factor (LORA_SF) nos dois firmwares, ou eles não vão se comunicar.

Orange Pi

A Orange Pi cumpre três papéis: hotspot WiFi para os celulares, servidor Flask com o painel, e ponte entre a Heltec base (USB) e o banco de dados. O passo a passo completo de configuração do hotspot, do Flask e do serviço de leitura da serial está em SETUP_ORANGE_PI.md, incluindo os comandos exatos de hostapd e dnsmasq testados nesse hardware.

Testar sem hardware

Antes de montar os sensores, dá para testar o painel inteiro com dados simulados:

python3 preencher_db.py   # gera 24h de dados de uma vez
python3 app.py            # sobe o servidor

Acesse http://192.168.4.1:5000 (ou localhost:5000 se estiver testando no próprio computador) e confira se os gráficos de todos os períodos (1h, 3h, 6h, 12h, 24h) aparecem preenchidos.

Uso em sala de aula

  1. Ligue a Orange Pi — o hotspot EstacaoMeteo aparece em alguns segundos.
  2. Ligue as duas Heltecs — o nó remoto começa a ler e transmitir, a base recebe e repassa.
  3. Os alunos conectam o celular no WiFi e abrem 192.168.4.1:5000.
  4. O painel mostra os dados em tempo real, com histórico e exportação em CSV para os alunos analisarem em planilha.
